WORKFLOW FLOW:

Sound Design Brief
        ↓
   [User fills form]
        ↓
POST /api/music/profiles
        ↓
sound_design_profiles record created
        ↓
Hub shows: "design" status
        ↓
User clicks: "Create Soundbank and Upload Stems"
        ↓
Soundbank stage with 2-step form
        ↓
POST /api/music/soundbanks + POST /api/music/stems (x7)
        ↓
stems records created + total_stems updated
        ↓
Hub shows: "soundbank" status (7 stems)
        ↓
User clicks: "Extract Clips"
        ↓
POST /api/music/clips (x24 clips)
        ↓
clips records created + total_clips updated
        ↓
Hub shows: "clips" status (24 clips)
        ↓
User clicks: "Run Soundsmith Validation"
        ↓
POST /api/music/validate-soundbank
        ↓
executeSoundsmithAgent() → 100-point assessment
        ↓
production_feedback record stored
        ↓
If VALID: Hub shows "validation" status, next: "Venom scoring"
If NEEDS_REVISION: Red alert with blockers
        ↓
User fixes issues or moves to Venom
        ↓
Venom scores soundbank (100-point scale)
        ↓
If APPROVE (80+): Hub shows "approval" status, next: "DARKSCO"
If REVISE: Orange alert with feedback
        ↓
User implements feedback or proceeds to DARKSCO
        ↓
DARKSCO workflow (7 agents + 6 quality gates)
        ↓
All agents review + Doom makes final decision
        ↓
If APPROVED: Hub shows "released" status, ✓ Complete
        ↓
Project finished → Ready for distribution
