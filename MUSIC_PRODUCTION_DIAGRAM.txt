┌─────────────────────────────────────────────────────────────────────────────┐
│                              PHASE 1: SOUND DESIGN                           │
│                         (User defines production vision)                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  SoundDesignBrief Component (/music page, stage 1)                          │
│  ├─ Form Inputs:                                                            │
│  │  ├─ Project Name (e.g., "Night Protocol 002")                           │
│  │  ├─ Style (e.g., "dark techno", "ambient")                              │
│  │  ├─ BPM (optional)                                                       │
│  │  ├─ Key (optional, e.g., "A minor")                                      │
│  │  ├─ Description (vision, goals)                                          │
│  │  ├─ Instrumentation[] (multi: bass, pad, drums, fx, strings, etc)      │
│  │  └─ Mood Keywords[] (multi: cinematic, intense, atmospheric, etc)       │
│  │                                                                          │
│  └─ Submission: POST /api/music/profiles                                   │
│     └─ Creates SoundDesignProfile in Supabase                              │
│        └─ Status: "brief" → "in-progress" (when validation starts)         │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                         PHASE 2: SOUNDBANK CREATION                          │
│                    (Create versioned collection of stems)                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  SoundbankCreator Component (/music page, stage 2)                          │
│  ├─ Stage 2a: Create Soundbank                                              │
│  │  ├─ Soundbank Name (e.g., "Night Protocol v1.0")                        │
│  │  ├─ Description                                                          │
│  │  └─ Auto-versioning (detects latest version, increments)                │
│  │     └─ Status: "draft"                                                  │
│  │                                                                          │
│  ├─ Stage 2b: Upload Stems                                                 │
│  │  └─ For each stem:                                                       │
│  │     ├─ Name (e.g., "Bass - Sub 808")                                    │
│  │     ├─ Instrument Type (bass, pad, lead, drums, fx, etc)               │
│  │     ├─ Category (melodic, percussive, textural)                        │
│  │     ├─ File Path (Vercel Blob storage)                                 │
│  │     ├─ Audio Metadata:                                                   │
│  │     │  ├─ Duration (seconds)                                            │
│  │     │  ├─ Sample Rate (48000, 44100, etc.)                             │
│  │     │  ├─ Bit Depth (24, 32)                                            │
│  │     │  ├─ Format (WAV, AIFF)                                            │
│  │     │  ├─ Frequency Range (optional)                                    │
│  │     │  ├─ Dynamics (optional)                                           │
│  │     │  └─ Processing (optional)                                         │
│  │     └─ POST /api/music/stems                                            │
│  │        ├─ Creates Stem record                                           │
│  │        ├─ Increments soundbank.total_stems                              │
│  │        └─ Updates soundbank.status → "stems-collected"                  │
│  │                                                                          │
│  └─ Finalize: Move to next stage                                            │
│     └─ Status: "stems-collected"                                           │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                      PHASE 3: CLIP EXTRACTION                                │
│              (Extract playable segments from stems with versions)            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  Clip Extraction Process:                                                   │
│  └─ For each stem:                                                           │
│     ├─ POST /api/music/clips                                               │
│     ├─ Extract segment: start_time → end_time                              │
│     ├─ Create Clip record:                                                 │
│     │  ├─ Name (segment identifier)                                        │
│     │  ├─ Duration (auto-calculated)                                       │
│     │  ├─ Loop Points (optional)                                           │
│     │  ├─ Tempo Sync (boolean)                                             │
│     │  ├─ Tags (attack, sustain, tail, loop-ready, etc)                   │
│     │  └─ Metadata (key, frequency_peak, loudness_db, etc)                │
│     │                                                                       │
│     └─ Clip Versioning:                                                    │
│        ├─ version_number (1, 2, 3...)                                      │
│        ├─ changes_made (description of revision)                           │
│        ├─ is_current (tracks active version)                               │
│        └─ created_by / created_at                                          │
│                                                                              │
│  Auto-Tracking:                                                             │
│  ├─ Increments soundbank.total_clips                                       │
│  └─ Updates soundbank.status → "clips-extracted"                           │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                    QUALITY VALIDATION & APPROVAL                             │
│              (Soundsmith → Venom → All 7 Agents → Release)                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  SOUNDSMITH AGENT (Chief Sound Design Officer)                              │
│  ├─ Validation Input:                                                       │
│  │  ├─ Profile: style, instrumentation, mood_keywords                     │
│  │  ├─ Soundbank: stems_count, total_duration                             │
│  │  └─ Metadata: bpm, key, description                                     │
│  │                                                                          │
│  ├─ 4-Point Assessment:                                                    │
│  │  ├─ Style Authenticity (0-100)                                          │
│  │  ├─ Instrumentation Coherence (0-100)                                   │
│  │  ├─ Mood Alignment (0-100)                                              │
│  │  └─ Production Readiness (0-100)                                        │
│  │                                                                          │
│  ├─ Quality Checks:                                                        │
│  │  ├─ Style Definition → pass/fail                                        │
│  │  ├─ Instrumentation Coverage → pass/fail                                │
│  │  ├─ Mood-Style Alignment → pass/warning                                │
│  │  └─ Stem Organization → pass/warning                                   │
│  │                                                                          │
│  ├─ Decision:                                                              │
│  │  ├─ VALID (≥75 score) → Approve, proceed to Venom                      │
│  │  ├─ INCOMPLETE (< 75) → Request development                            │
│  │  └─ NEEDS_REVISION → Return for revisions                              │
│  │                                                                          │
│  ├─ Output: production_feedback record (JSONB stored)                     │
│  │  ├─ Score, findings, recommendations, blockers                         │
│  │  ├─ agent_response (complete response)                                 │
│  │  └─ decision: approve | revise | reject                                │
│  │                                                                          │
│  └─ Update: soundbank.status → "quality-check"                             │
│                                                                              │
│  POST /api/music/validate-soundbank calls Soundsmith                       │
│                                                                              │
│  ↓ If VALID:                                                               │
│                                                                              │
│  VENOM AGENT (Chief Music Officer)                                         │
│  ├─ Input: Soundbank + stems + clips                                       │
│  │                                                                          │
│  ├─ 100-Point Quality Scoring:                                             │
│  │  ├─ Identity (20 pts): Style adherence                                 │
│  │  ├─ Mix Quality (20 pts): Frequency, headroom, clarity                 │
│  │  ├─ Arrangement (20 pts): Structure, transitions, flow                 │
│  │  ├─ Emotional Impact (15 pts): Mood, engagement                        │
│  │  ├─ Originality (15 pts): Uniqueness, creativity                       │
│  │  └─ Licensing (10 pts): Rights, metadata readiness                     │
│  │                                                                          │
│  ├─ Decision:                                                              │
│  │  ├─ 80+ → APPROVE (production-quality, ready for DARKSCO)              │
│  │  ├─ 60-79 → REVISE (needs adjustments, specific feedback)              │
│  │  └─ <60 → REJECT (below standard, major revision needed)               │
│  │                                                                          │
│  └─ Update: soundbank.status → "approved"                                  │
│                                                                              │
│  ↓ If APPROVED:                                                            │
│                                                                              │
│  DARKSCO WORKFLOW INTEGRATION                                              │
│  ├─ Create darksco_workflow for soundbank                                  │
│  ├─ Create soundbank_releases record (links to workflow)                   │
│  ├─ Pass through all 7 agents:                                            │
│  │  ├─ Venom (Music): ✓ Already scored                                    │
│  │  ├─ Hela (Visual): Album art, imagery validation                       │
│  │  ├─ Loki (Publishing): Files, metadata, premiere ready                 │
│  │  ├─ Bane (Evidence): Metrics, positioning                              │
│  │  ├─ Thanos (Rights): Master, composition, samples, visuals            │
│  │  ├─ Doom (Strategy): All gates + final decision                        │
│  │  └─ Darkside (Orchestration): Minimum viable execution                 │
│  │                                                                          │
│  ├─ Quality Gates (6 per workflow):                                        │
│  │  ├─ Music (Venom): passed (100-point score ≥80)                        │
│  │  ├─ Visual (Hela): pass/fail                                           │
│  │  ├─ Publishing (Loki): pass/fail                                       │
│  │  ├─ Evidence (Bane): pass/fail                                         │
│  │  ├─ Rights (Thanos): pass/fail                                         │
│  │  └─ Final (Doom): APPROVED/REVISE/REJECT                               │
│  │                                                                          │
│  └─ Final Decision:                                                        │
│     ├─ All gates PASSED → RELEASED                                         │
│     ├─ Some gates FAILED → REVISE (return to agents)                      │
│     └─ Major blockers → REJECT (major rework needed)                      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
