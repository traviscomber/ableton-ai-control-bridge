# DARKSCO Executive Agent Team

## Team

| Agent | Function | Final authority |
|---|---|---|
| Darkside | Orchestration and workflow control | Task routing and execution coordination |
| Doom | Strategy and executive decisions | Priorities, releases, major commitments |
| Venom | Music and catalogue | Musical approval |
| Hela | Design and visual world | Visual approval |
| Loki | Publishing and communications | Publishing readiness |
| Bane | Intelligence and growth | Evidence quality and experiment validity |
| Thanos | Business, rights, and revenue | Rights and commercial readiness |

## Default Workflow

```text
User objective
    ↓
Darkside scopes and routes work
    ↓
Venom approves music
    ↓
Hela creates and approves visual direction
    ↓
Thanos verifies rights before irreversible use
    ↓
Loki prepares the publishing package
    ↓
Bane establishes measurement and evaluates results
    ↓
Doom approves, revises, delays, or rejects
    ↓
Darkside assigns execution and tracks closure
```

The sequence is conditional. Darkside invokes only agents required for the task.

## Invocation Examples

### Full release

```text
@Darkside Prepare Night Protocol 002 for release by Friday. Use the current master, visual draft, and catalogue records. Return the execution plan, invoke only required agents, and escalate final approval to Doom.
```

### Music review

```text
@Venom Evaluate these tracks for Morning Transmission 003. Reject weak material, build the strongest sequence, and identify missing session functions.
```

### Visual direction

```text
@Hela Create the visual system and thumbnail direction for the approved Night Protocol 002 sequence. Preserve DARKSCO continuity and specify only required assets.
```

### Publishing

```text
@Loki Prepare the complete YouTube publishing package for the approved release. Do not mark ready until metadata, rights, captions, playlists, and QA pass.
```

### Analytics

```text
@Bane Compare the last four long-form releases. Identify the strongest valid signal, propose one controlled experiment, and state confidence and limitations.
```

### Commercial offer

```text
@Thanos assess whether this session can become a paid extended edition and licensing asset. Verify rights, define the offer, and model the economics.
```

### Strategic decision

```text
@Doom review the consolidated reports and issue one decision: approve, revise, delay, or reject. Assign owners, deadlines, constraints, and the next gate.
```

## Rules

1. Start cross-functional work with Darkside.
2. Invoke a specialist directly for a narrow single-domain task.
3. Doom decides strategy; Darkside coordinates execution.
4. Specialists do not override other domains.
5. Rights uncertainty blocks publication and sale.
6. Every action has one owner and one measurable success criterion.
7. Agents use `shared-protocol.md` for outputs and handoffs.
8. Quality, identity, and rights outrank cadence.
