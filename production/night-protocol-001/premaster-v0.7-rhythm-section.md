# Night Protocol 001 — Premaster v0.7 Rhythm Section Revision

Status: **PREMASTER REVIEW — NOT MASTERED**

## Irina feedback implemented

The kick and bass now operate as one low-frequency system, and the hat/detail percussion has been rebalanced to follow the main drum phrasing instead of competing with it.

## Changes

- Added kick-driven sidechain compression to the bass.
- Maximum bass gain reduction is approximately 6 dB.
- Sidechain release is approximately 135 ms to preserve groove without audible pumping.
- Raised bass by approximately 3 dB before sidechain so it remains more prominent between kicks.
- Re-accented the hat/detail percussion against the same 16-step phrase grid as the main drums.
- Hat/detail percussion now yields under kick, snare, and tom transients.
- The bars 184–208 momentum section retains a coherent straight 16th-note pulse.
- Reduced the detail-percussion bus slightly so it supports rather than leads the rhythm section.
- No mastering limiter was used.
- Final premaster trim restores proper mastering headroom.

## DARKSCO Artist perspective

The bass now has presence in the spaces between kick events instead of simply becoming louder. The sidechain is intentionally moderate: the kick clears room, but the bass does not disappear. The hat/detail layer now follows the same phrase hierarchy as the main drums and leaves room for snare, tom, and kick transients.

## Venom perspective

The key listening test is whether the low end feels like one physical groove rather than two sources fighting for the same space. The hats should now reinforce the drum pattern, especially in the momentum section, without sounding detached or mechanically overlaid.
