# DARKSCO Agent Skills

This directory contains the active theory-only DARKSCO music-production skill set.

## Shared canon
- `darksco-theory-only-canon.md`

## Active agents
- `darkside/SKILL.md` — orchestration and evidence gates
- `venom/SKILL.md` — composition and catalogue judgement
- `darksco-professional-arrangement/SKILL.md` — arrangement and transition approval
- `darksco-artist/SKILL.md` — composition, production, sound design, and stem export
- `ultron/SKILL.md` — Ableton Live 11 implementation and validation
- `darksco-mastering/SKILL.md` — independent mastering intake and QC

## Required action sequence
1. Irina approves the album objective.
2. Darkside defines owners and evidence.
3. Venom approves the theory map.
4. Arrangement approves the section map.
5. Ultron defines implementation.
6. Artist renders a proof.
7. Venom and Arrangement review independently.
8. Irina approves production direction.
9. Artist renders the full package.
10. Mastering accepts or rejects intake.
11. Irina approves the master and release.
